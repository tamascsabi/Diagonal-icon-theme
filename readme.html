Diagonal Icon Theme

A modern, colorful icon theme for Linux and BSD systems

Overview

Diagonal Icon Theme is a carefully designed icon set inspired by well-known themes such as Yaru, Evolvere, and WhiteSur. The goal of the project is to provide a visually consistent, modern, and highly customizable icon experience across different desktop environments.

The theme focuses on clarity, balanced color usage, and a unified design language, making it suitable for both minimal and feature-rich desktop setups.

Features

  • Interactive installer with guided setup
  • POSIX-compliant shell scripts (no Bash dependency)
  • Compatible with Linux and *BSD systems
  • Support for multiple desktop environments
  • Customizable folder color variants
  • Portable mode (build icon package without installation)
  • Prebuilt icon packages included for major desktop environments
  • Cursor themes with light/dark and color variations
  • Automatic system detection with manual override

Compatibility

The project is designed with portability in mind and avoids non-standard shell features. All scripts follow POSIX guidelines to ensure maximum compatibility.

  • POSIX shell compatible
  • Tested on Linux distributions and *BSD systems
  • No Bash-specific features required

Tested Shells

  • sh (POSIX)
  • dash
  • ash

Installation

The recommended way to install the theme is by cloning the repository and running the installer. 

$ git clone https://github.com/tamascsabi/Diagonal-icon-theme.git

 $ cd Diagonal-icon-theme
 $ ./install.sh

The installer will guide you through the configuration process, including selecting your desktop environment and preferred color scheme.

Prebuilt Icon Packages

For users who prefer a quick setup, prebuilt icon packages are available for each supported desktop environment. These packages can be extracted directly without running the installer. 

~/.icons/
 ~/local/share/icons

 or

 /usr/share/icons/

This allows immediate use of the theme without any additional configuration steps.

Portable Mode

The installer can also be used to generate a compressed icon package without installing it. This is useful for transferring the theme to other systems or creating backups.

Uninstallation

The included uninstall script ensures safe removal of the theme from your system. 

./uninstall.sh
